# SPEC — K3 源泉徴収・支払調書の税リファレンス（国税庁 一次情報照合）

経営セッション発。Kyually **K3**（業務委託＝掲載報酬の源泉分離＋支払調書 任意）の**法定数値の一次根拠**。
★**捏造禁止・自己参照禁止**：下記はすべて国税庁タックスアンサーで照合済み。実装は**この数値で実数値テスト**を先に書き、公式の計算例と**1円まで一致**させること。

---

## 0. 大原則（K1/K2の現状維持＝崩すな）
- **所得税法204条は「限定列挙」**。列挙された区分だけが源泉徴収の対象。
- ★**運転代行・運送・軽貨物配送は8区分に含まれない＝源泉なし・支払調書なし**（K0仕様どおり）。
  **K3で"全業務委託に源泉"を掛けてはいけない。** 既定は「**非該当（源泉なし）**」。
- 源泉義務者：**給与を支払う個人・法人**（合同会社ZEROactは該当）。参照 No.2793。
- **復興特別所得税込み**の合算税率：`10.21% = 10%×1.021` ／ `20.42% = 20%×1.021`。
- **端数**：算出した税額の**1円未満は切り捨て**。

---

## 1. 区分別の計算式（実装する分＝グレー中小が実際に払う範囲）

### A. 一般の報酬・料金／士業（弁護士・税理士・公認会計士 等）
原稿料・講演料・デザイン料・工業所有権使用料・技芸指導料 等、および弁護士・税理士等の報酬。
- **100万円以下**：`支払額 × 10.21%`
- **100万円超** ：`(支払額 − 100万円) × 20.42% + 102,100円`
- 例：原稿料 **150万円** → `(150万−100万)×20.42% + 102,100 = 204,200円`
- 出典：[No.2795 原稿料や講演料等](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm) ／ [No.2798 弁護士や税理士等](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2798.htm)

### B. 司法書士・土地家屋調査士・海事代理士
- `(1回の支払額 − 10,000円) × 10.21%`
- 例：**50,000円** → `(50,000−10,000)×10.21% = 4,084円`
- 出典：[No.2801 司法書士等](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2801.htm)

### C. 外交員・集金人・電力量計検針人 等
- `(その月の報酬 − 120,000円) × 10.21%`
- ★**同月に給与も払う場合**：控除額は `120,000円 − その月に支払う給与等の額`（残額）。
- 出典：[No.2804 外交員等](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2804.htm)

> ※他の区分（社会保険診療報酬・プロスポーツ選手・芸能・ホステス・馬主賞金 等）は司さんの業種で実需が薄い。**まずA/B/C＋"非該当"を実装**し、他は「その他（要確認・非該当扱い）」で逃がす（捏造で率を作らない）。

## 2. 課税対象額（消費税の扱い・インボイス後）
- 源泉の対象額は**原則「税込」**。
- ただし請求書等で**報酬額と消費税額が明確に区分**されていれば、**税抜の報酬額**を対象額にできる。
- 出典：[No.6929 消費税等と源泉所得税及び復興特別所得税](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6929.htm)
- 実装：対象額の「税込/税抜」を**選べる**ように（既定は税込・安全側）。

---

## 3. 支払調書「報酬、料金、契約金及び賞金の支払調書」— 提出範囲
その年の**同一人への合計**が下記を**超える**とき提出（翌年1/31まで）。出典：[No.7431](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hotei/7431.htm)
| 区分 | 提出基準（年・超で） |
|---|---|
| 弁護士・税理士等（士業） | **5万円** |
| 原稿料・講演料 等 | **5万円** |
| 外交員・ホステス等 | **50万円** |
| 社会保険診療報酬 | **50万円** |
| （馬主賞金 = 1回75万円超 等は対象外業種） | — |
- ★**運転代行・運送は非該当＝支払調書の対象外**。「任意生成」でも**代行にはデフォルトで出さない**。

## 4. 実装の要点（決定論・グレーは非ブロック・断定禁止）
1. **区分は人ごとに選ぶ**：従業員マスタの「業務委託」の下に**源泉区分チップ**を足す（K1の雇用形態チップと同じ操作感）。
   - 既定 = **`非該当（源泉なし）`**（代行/運送を守る）。
   - `一般報酬/士業(A)` ／ `司法書士等(B)` ／ `外交員(C)` ／ `その他(要確認・非該当扱い)`。
2. **区分を選んだ時だけ**源泉計算＋支払調書対象。非該当は従来どおり支給＝支払額（K1のまま）。
3. **計算は決定論**（きく/AIに数値を作らせない）。端数1円未満切捨。
4. **断定しない**：区分判定が曖昧なときは**非該当のまま＋黄注記**（「掲載報酬に当たる可能性。当たる場合のみ区分を選択」）。掛け過ぎ厳禁。
5. **明細表記**：源泉ありは「報酬明細（源泉徴収 −◯◯円）」、非該当は現状の「報酬明細」。

## 5. DoD（司さんに報告する前に必ず）
- **実数値テスト先行**（自己参照禁止）：
  - A：`150万円 → 204,200円`、境界 `100万円 → 102,100円`、`99万円 → 101,079円`
  - B：`50,000円 → 4,084円`、`10,000円以下 → 0円`
  - C：`月20万・給与0 → (200,000−120,000)×10.21% = 8,168円`、`給与併給で控除残0以下 → 0円`
  - **非該当（代行）→ 源泉0・支払調書0**（回帰）。
- 対立監査（区分取り違え／端数／税込税抜／給与併給の控除残）。
- 実UI確認（区分選択→源泉額表示→代行は0のまま）。
