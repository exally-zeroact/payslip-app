# 給与明細アプリ（ZEROACT / payslip-app）

ブラウザで日本の給与明細を作成・計算・プレビュー・印刷(PDF)・Excel出力できる Web アプリ。
所得税・社会保険・雇用保険・住民税・割増賃金などを**法令に沿って自動計算**し、選んだテンプレートで明細を描画します。
（代行請求アプリ Exally と同系のミントUI。まず localStorage 保存、Supabase 対応の作り）

## 主な機能

### 設定
- **会社情報**：会社名/住所/締め日/支給日（当月・翌月＋日）、会社の決まり（割増率・欠勤控除・支払基礎日数・代休/振替・会社独自休 など。長い注記は💡で詳細）
- **従業員マスタ（2段）**：基本（氏名/給与形態/額/都道府県/通勤手当）＋「詳細設定」（社保・法定控除・扶養・乙欄・入社/退職日・就業状況・支給/控除項目・住民税・振込先）。在籍中/休暇中/退職者/全員で絞り込み、並べ替え
- **明細デザイン**：配色プリセット5種（クラシック紺/セピア/グレー/ミント/モノクロ）＋個別微調整（アクセント/罫線/文字）、レイアウト6テンプレを**手動選択**

### 入力（毎月）
- 月次給与 / 賞与 をトグル。従業員をコンパクト一括入力（勤怠・残業・変動手当を1画面）、手取り即更新
- **未入力/確認ハイブリッド**：前月比（自動）＋確認✓（手動）、進捗「確認 X/Y名」＋未確認バッジ、「今月を確定」で保存
- 勤怠カレンダー：祝日を自前計算し所定労働日数を算出、「全員の出勤を所定で埋める」

### 計算エンジン（lib/・すべて純関数＋テスト）
- **所得税**：電算機計算の特例（甲欄/乙欄・令和7/令和8を対象月で自動選択）
- **社会保険**：標準報酬月額（定時決定/資格取得/随時改定/直接入力、既定は基本給から自動）、健保47都道府県＋介護＋子ども子育て支援金を**年度で自動切替**
- **割増賃金**：時間外1.25/深夜+0.25/法定休日1.35/月60h超/固定残業（みなし）控除、率オーバーライド、端数（基発150号）
- **歩合給・保障給**：出来高払（歩合÷総労働時間の割増）＋労基27条の保障給
- **住民税**：特別徴収（年額12分割・6月端数・退職時一括/普通徴収）
- **産育休の社保免除**：月末在籍基準＋令和4年10月の14日ルール、賞与は連続1か月超
- **賞与**：標準賞与額・健保年度累計573万/厚年150万上限・算出率表
- **最低賃金**：地域別最賃と時間額を比較して黄色警告
- 入社/退職の日割、欠勤控除（日給月給制）、通勤非課税（公共15万/マイカー距離別）

### 一覧 / 集計 / 出力
- 月次集計（従業員別）＋控除の内訳（本人負担）＋**納付の目安**（源泉・住民・社会保険・雇用）
- **要確認**（最賃割れ・差引マイナス・休業手当未入力）を集計とExcelに表示（従業員に渡す明細PDFには出さない）
- 印刷 / PDF（A4 縦/横をテンプレに応じ自動）、Excel出力（給与集計＋従業員別明細シート）

## テンプレート（手動選択・6種）
`prefer` で固定。全員を自動ページ分割（誰も欠けない）。
- `col2_1` / `col2_2` / `col2_3` … 2カラム（支給｜控除 横並び）を 1人/2人/3人ずつ
- `col1_1` / `col1_2` / `col1_3` … 1カラム（支給↓控除 縦積み）を 1人/2人/3人ずつ

※ 旧「人数・項目数からの自動選択」は廃止（ユーザーが明細デザインで選ぶ方式）。関連の未配線モジュール `lib/select.js` は撤去済み。テンプレ収まり容量は render.js のコメント参照。

## 年度依存の法定数値について（重要）
健保47県・最賃47県・雇用保険率・介護率・標準報酬上限・通勤非課税・所得税算出率などの**年度で変わる値は、公式一次情報（協会けんぽ/厚労省/国税庁/e-Gov）で照合し、"実数値"をテストでロック**しています（推定・据え置き・自己参照テストは禁止）。新年度更新時は必ず公式PDF/ページから取得→実数値テスト追加→出典URL＋照合日をコメント。

## テスト
```
node tests/run.js
```
純関数（lib/*）の単体＋computePayslip通しの統合＋年度別法定数値の実数値ロック。

## Supabase を有効化する
1. Supabase プロジェクト作成 → `pay_companies` / `pay_employees` / `pay_payslips` を用意（Exallyと同倉庫・棚別）
2. `js/supa-config.js` に `window.SUPA = { url, key(anon public) }`（RLSで保護・anon公開可）
3. store.js の列名マップを本接続に合わせる

## デプロイ（Vercel）
静的サイト。本番 = `payslip-app-olive.vercel.app`（main へ push で自動デプロイ）。

## 用途
中小企業の給与明細作成を想定（グレー中小がメイン・設定は寛容/計算は厳密）。最終判断は会社・社労士で。
